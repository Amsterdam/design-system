## Usage guidelines

### When to use

Use this page for reference material long enough to need splitting: a personnel handbook, a policy document, a set of regulations.

### When not to use

Use an [Information Page](/docs/pages-public-information-page--docs) where a single page carries the whole topic.

## Structure

- Two [Skip Links](/docs/components-navigation-skip-link--docs) at the top of the page let keyboard users jump straight to the table of contents or to the content.
- The page uses a two-column [Grid](/docs/components-layout-grid--docs) layout.
- The left column holds a collapsible [Table of Contents](/docs/components-navigation-table-of-contents--docs) showing the full document tree.
  - Set `aria-current="page"` on the active link.
  - Drive each branch with the controlled `expanded` prop and an `onToggle` handler, so the current position stays open as the reader moves through the document.
    Keeping the Table of Contents mounted means the link a keyboard user just activated never loses focus.
- The right column contains a `main` element using the [Prose](/docs/utilities-css-prose--docs) utility class.
  - Each page opens with a Content Header: a level 1 [Heading](/docs/components-text-heading--docs) followed by a large lead [Paragraph](/docs/components-text-paragraph--docs), then body text.

## Layout and spacing

- The Grid uses the [recommended Cell sizes](/docs/pages-guidelines-layout-and-spacing--docs#how-to-size-the-grid-cells).
- The Prose utility class handles vertical spacing within the content area automatically.

## Accessibility

This page has two places worth reaching, so it declares two Skip Links rather than the single one every other template carries: one targets the Table of Contents, the other the `id` on `main`.

The entry for the page on screen carries `aria-current="page"`, which a screen reader announces along with the link.

The Table of Contents stays mounted as the reader moves from page to page.
The link they just activated therefore keeps focus, where a navigation rebuilt per page would drop it back to the top of the document.
