# Example photos

These local copies keep Storybook examples and visual tests independent of an external image service.
Keep the neutral file names when replacing the photos.

The base photos retain their original aspect ratios, rounded to whole pixels, at widths of at most 1440 pixels.
Some use smaller widths to keep every file below 200 kB.
Image, Card Image, and Image Slider crop them through CSS.
Responsive examples deliberately reuse the same file for each width descriptor.

The size-suffixed files preserve the intrinsic dimensions tested by Avatar and the plain images in Breakout, Figure, and Overlap.
The portrait file lets the Image and Card visual tests exercise containing and covering an image.
Documentation stories use different base photos, whose aspect ratios also differ from their boxes.
