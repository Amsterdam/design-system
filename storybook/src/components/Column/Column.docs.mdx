## Usage guidelines

### When to use

Wrap a Column around a set of elements that need the same amount of white space between them.

### When not to use

Do not use a Column for text – various types of elements require different amounts of space between them.
Wrap editorial content in the [Prose](/docs/utilities-css-prose--docs) utility class to have all spacing set automatically.

To add white space below a single element, use [Margin Bottom](/docs/utilities-css-margin--docs) instead.

### How to use

Give a Column a name when you set `as="section"`.
A `section` reaches assistive technology as a landmark only once it has one, so give the heading inside it an `id` and point `aria-labelledby` at that id.
Without a name the element groups the content in the markup but adds nothing anyone can navigate to.

## Examples

### Alignment

Items in the column can be aligned vertically in several ways:

- **Center**: center items within the column.
- **End**: align items to the bottom of the column – to the bottom.
- **Space Between**: distribute whitespace between items.
- **Space Around**: distribute whitespace around items.
- **Space Evenly**: distribute whitespace evenly around items.

By default, items align to the **start** of the column – at the top.
This option has no class name or prop value.

This example centers three items vertically.

### Horizontal alignment

Items in the column can be aligned horizontally in several ways:

- **Start**: align items to the start of the column. This is the left side in left-to-right languages.
- **Center**: center items within the column.
- **End**: align items to the end of the column. This is the right side in left-to-right languages.

## Features

Five sizes of [space](/docs/brand-design-tokens-space--docs) are available for the width or height of the gap.
The medium gap is the default.

Align the elements horizontally or vertically through the alignment props.

## Design

The gap is the only spacing a Column provides.
There is no padding, no margin, and no divider between items, so the space belongs to the container and the items keep whatever spacing they define for themselves.

All five gaps scale with the width of the window rather than stepping at a breakpoint.
The white space in a layout therefore grows in proportion with the type and the grid around it, instead of holding still until a threshold is crossed.

Every item in a Column gets the same gap, which is why ‘When not to use’ steers editorial text towards [Prose](/docs/utilities-css-prose--docs).
A heading needs less space above the paragraph it introduces than below the one before it, and a single gap cannot express that.

## Accessibility

A Column renders a `div` by default, which adds nothing to the accessibility tree.
Its items are announced exactly as they would be without it, in the order they appear in the markup.

The `as` prop can render an `article` or a `section` instead, which does reach assistive technology.
‘How to use’ covers what a `section` needs before it becomes a landmark.
