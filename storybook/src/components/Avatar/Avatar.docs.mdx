## Usage guidelines

### When to use

Show an Avatar for the user of the website, or to associate a person with a content item.

## Examples

### With image

The Avatar can also display a photo or other image for the person.
Make sure to scale the image down to around 100 pixels to prevent unnecessary data transfers.
The center of the image will be visible; provide a square image if possible.

<Canvas of={AvatarStories.WithImage} />

### Fallback icon

A user icon displays if no label and image are provided.

<Canvas of={AvatarStories.FallbackIcon} />

## Design

The Avatar contains 1 or 2 initial letters from the person’s full name, a picture, or a generic icon.
The component takes the first two characters of the label and sets them in capitals, so the shape stays the same however the name was written.

To personalize the Avatar, the user can be allowed to choose one of the [highlight colours](/docs/brand-design-tokens-colour--docs).
The default is purple.
The design system does not define a meaning to any of these background colours.

The circle is sized from the text it holds rather than from a fixed measurement: its width follows the font size and line height of the initials.
An Avatar showing an image drops the border and grows by exactly the space that border and its padding occupied, so both kinds line up at the same size beside each other.

An image is cropped to the circle from its centre and scaled to cover it, whatever proportions it arrives in.
A portrait that is not square therefore loses its edges rather than distorting.

In print, an Avatar keeps its background colour instead of being flattened to save ink.

## Accessibility

An Avatar is announced exactly once, through a line of text that is in the markup but hidden visually.
The initials themselves are marked `aria-hidden`, and an image is given an empty `alt`.

That hidden text is fixed Dutch: ‘Initialen gebruiker’ followed by the initials, or ‘Gebruiker’ when the label is empty and the fallback icon shows.
It is built from the label even when an image is displayed, so an Avatar showing a photograph is still announced by its initials.
The wording cannot be configured, which is worth weighing before using an Avatar on a page in another language.
