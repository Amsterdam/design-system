## Usage guidelines

### When to use

Use an Image Slider for a series of images that belong together.

### When not to use

Assume that some or many users will not navigate between the slides and only see the first image.
Display all images separately if you want each of them to receive attention.

### How to use

Each entry in `images` accepts the props of an [Image](/docs/components-media-image--docs), such as `aspectRatio` and `srcSet`, plus an optional `caption`.
Every image needs its own `alt`.

Provide `accessibleName` to give the Image Slider a meaningful name for screen reader users.
If skipped, the slider uses the generic label ‘Afbeeldingen’.

Provide at least 2 images and at most 5.
Feature the most essential image first.

A full-width Image Slider should run from one edge of the [Page](/docs/components-containers-page--docs) container to the other; position it next to a Grid, not in a Cell spanning all columns.
Smaller sliders are fine in a Grid Cell.

## Examples

### Responsive images

Provide a set of smaller and larger instances for every image (through `srcSet`, see [MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/img#srcset)) to let the browser select the optimal source file.
A mobile device can often download a smaller file, saving the user’s bandwidth and time.
Don’t forget to still include the required `src` attribute.

<Canvas of={ImageSliderStories.ResponsiveImages} />

### With captions

Add a caption to any image to display a description below it, e.g. for context or attribution.
Keep captions short – they take up vertical space, especially on mobile.
Consistent caption lengths across images help avoid large layout shifts when sliding.

## Design

The first or selected image shows at its maximum size.
Every image displays a thumbnail at about 20% of its width.
Users can use buttons, thumbnails, or swiping to navigate between the images.
The buttons are not displayed on a narrow touch device.
The images do not slide automatically.

In a right-to-left writing direction the images and the previous and next buttons follow the reading order, so the previous image sits to the right and the next to the left.
See the [localisation guide](/docs/docs-guidelines-localisation--docs) for the design system’s writing-direction support.

The thumbnail strip always divides its width into five, whether there are two images or five.
Thumbnails then keep the same size across every Image Slider on a site instead of stretching to fill the row.

A thumbnail that is not in view is drawn at 40% opacity, and the one in view at full strength.
Fading the rest is what marks the current image without adding a border or a marker that would crop into the picture.

The previous and next buttons are hidden on a narrow screen with a coarse pointer.
Swiping is already the natural gesture there, and the buttons would cover a sizeable part of a small image.

Sliding is animated only for users who have not asked for reduced motion.
Everyone else is moved to the next image directly, with no travel across the screen.

## Accessibility

The images are in a live region that politely announces when the current image changes.
A screen reader user hears an update after using the previous or next button, a thumbnail or swiping.

Only the current image is exposed to assistive technology.
The other images are hidden so a screen reader does not read all images at once.

The thumbnails use the tab pattern.
Each thumbnail controls its matching slide and the slide is labelled by its thumbnail.
The current slide can receive focus, which helps keyboard users know which slide they are on.

Each thumbnail uses the image’s alt text as its accessible name.
The value of the `imageLabel` prop is placed before the alt text, for example: ‘Afbeelding: Het stadhuis van Amsterdam’.
The tab list provides the position and total number of thumbnails automatically, so this information does not need to be repeated in the name.

Use ArrowLeft and ArrowRight to move between thumbnails.
Only the selected thumbnail can be reached with Tab, so the whole thumbnail strip can be passed in one step.

The focus outline of a thumbnail is never dimmed.
Only the thumbnail image becomes less visible when it is not selected.
