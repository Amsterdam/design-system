## Usage guidelines

### When to use

Use a File Input when users need to attach one or more files from their device.

### How to use

Wrap a File Input in a Field to associate it with a Label and description.

## Examples

### Multiple files

Allow multiple files to be selected.
The label will update to show the number of files selected.

<Canvas of={FileInputStories.MultipleFiles} />

### Restrict file types

Limit the types of files that can be selected.
Some examples are `image/*`, `video/*`, or `audio/*`.
To limit to a specific file type, use the MIME type, such as `application/pdf`.

- [MDN File Input](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/file#limiting_accepted_file_types): More examples

## Design

The filename label and button are displayed in the language of the browser and can vary between browsers and operating systems.

The field itself gets the border, padding and type of the other form fields, and the button the browser draws inside it is restyled to look like a secondary [Button](/docs/components-buttons-button--docs).
Hovering thickens that button’s outline with an inset ring rather than a wider border, so nothing beside it moves.

The button takes the type of the field around it rather than setting its own.
Browsers give a file selector button a font of their own, and inheriting it is what keeps the control from looking like a piece of another interface.

## Accessibility

A File Input renders a native `input` of type file, so the file dialog, the keyboard behaviour and the list of chosen files all come from the browser and the operating system.

Both the button’s wording and the text stating what has been selected are generated by the browser, in the browser’s language rather than the page’s.
A visitor on a page in one language may hear that text in another, and nothing the page does can change it.

That text is not always current, either.
When the selection is changed in code, some browsers go on announcing a file that has been removed.
Do not send focus to the field after removing one: send it to something the page states in its own words, as the File List example does.

A [File List](/docs/components-forms-file-list--docs) beside the field is how a page states the selection in its own words and gives the user a way to remove a file.
