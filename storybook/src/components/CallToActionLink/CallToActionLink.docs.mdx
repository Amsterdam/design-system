## Usage guidelines

### When to use

Use a Call to Action Link to guide the user to a page where they can perform an action.

### When not to use

A single page must not have more than one Call to Action Link.
Ensure the emphasis is on one product, and divide the content into several pages if needed.

For additional guidelines, refer to the [Link](/docs/components-navigation-link--docs) component.

Use [Margin](/docs/utilities-css-margin--docs) or [Prose](/docs/utilities-css-prose--docs) to add vertical whitespace.

### How to write

Use the verb's infinitive form, such as "Kapotte parkeerautomaat melden", not "Meld kapotte parkeerautomaat".

## Design

The Call to Action Link features a green background to ensure it stands out.
To clarify that it is not a button, which is not suitable for navigation, its text is underlined like links typically are.
This informs users that a new page will open and that they can either copy the link or open it in a new window.

Green is not used for a [Button](/docs/components-buttons-button--docs) anywhere in the system, so the colour marks the difference as much as the underline does.

The corners are square and the vertical padding is slight, so the block hugs its line of text.
It reads as a highlighted link rather than as a large control, which is the distinction the underline is there to protect.

Because the block itself stays small, the space around it does the work of drawing the eye.
It takes an [x-large space](/docs/docs-designer-guide-vertical-space--docs) above and below it, where the body text it sits among takes medium, so it reads as the one action of the page rather than as another paragraph in the flow.
[Prose](/docs/utilities-css-prose--docs) applies that space; outside a Prose container, set it with the `ams-mb-xl` [Margin](/docs/utilities-css-margin--docs) utility class on the Call to Action Link and on the element above it.

In print, it keeps its background colour instead of being flattened to save ink.

## Accessibility

A Call to Action Link renders an `a` element, so it is announced as a link and listed among the links of the page, however much it looks like a button.

Someone who navigates by pulling up a list of links finds it there rather than among the controls, and hears where it goes rather than what it would do.
That is the distinction the underline makes visually and the element makes for everyone else.
