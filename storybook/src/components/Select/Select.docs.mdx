## Subcomponents

Provide the choices of the Select with Option subcomponents, and group related choices with a Group.
They render the native `<option>` and `<optgroup>` elements and accept their standard attributes only.

## Usage guidelines

### When to use

Use a Select when the user must pick one option from a list that is too long to display as Radios.

### When not to use

Avoid adding functionality to allow selecting multiple options.
Multi select is harder to use on desktop as they require the user to hold down the `Ctrl` or `Cmd` key while clicking on the options.
It is recommended to use checkboxes instead.

### How to use

Wrap a Select in a Field to associate it with a Label, description, and Error Message.

## Design

A Select shares its border, padding, type and states with a [Text Input](/docs/components-forms-text-input--docs), so a field the user types into and one they choose from sit level in the same form.

The chevron browsers draw is replaced by one of ours, and the field reserves room for it at the end so a long option never runs underneath.
It is drawn three times over — in the interactive blue, in the hover blue, and in grey when disabled — because a background image cannot take the colour of the text the way an icon in the markup would.

A Select showing several options at once keeps the native appearance and no chevron, since there is nothing to expand.

## Accessibility

A Select renders a native `select` element with native `option` and `optgroup` elements inside it.
The list that opens is the operating system’s own, so it behaves the way every other menu on that device does: the same keys, the same gestures, and the same behaviour with a screen reader, none of which the design system reimplements.

That is also the reason the appearance stops at the closed field.
An open list cannot be styled, and replacing it with markup we could style would mean rebuilding all of that behaviour.

A disabled option is greyed but still announced, so the user hears that a choice exists and is unavailable rather than not hearing it at all.
