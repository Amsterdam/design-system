This component has no props to configure.

Wrap File Cards in an [Unordered List](/docs/components-text-unordered-list--docs) without markers instead, and pass `previewUrl` to the File Card for a thumbnail, as the [With a File Input example on the File Card page](/docs/components-forms-file-card--docs#with-a-file-input) shows.

```diff
- <FileList>
-   <FileList.Item file={file} onDelete={remove} />
- </FileList>
+ <UnorderedList markers={false}>
+   <UnorderedList.Item>
+     <FileCard name={file.name} onDelete={remove} size={file.size} type={file.type} />
+   </UnorderedList.Item>
+ </UnorderedList>
```
