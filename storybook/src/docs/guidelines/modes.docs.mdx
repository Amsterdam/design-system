# Modes

The design system offers three modes, covering two different needs: how densely a page is packed, and how finished it looks.
Spacious Mode and Compact Mode set the density; Lo-fi Mode renders a page as a rough drawing.

## Density

The design system supports various kinds of websites.
The optimal layout can differ significantly between them.

Our visual style is quite spacious by default.
This works fine for content-oriented websites, but not so much for websites with a high information density.
We distinguish two levels of spaciousness to cover both needs.

1. **Spacious Mode** for public websites.
   Large type and generous spacing make reading comfortable.
2. **Compact Mode** for internal websites.
   Smaller text and tighter spacing allow showing more data.

Key characteristics of each mode:

|                           |               Spacious Mode               |                    Compact Mode                     |
| :------------------------ | :---------------------------------------: | :-------------------------------------------------: |
| **Audience**              |                  Public                   |                      Internal                       |
| **Canvas background**     | <InlineColorSample color="white" /> white | <InlineColorSample color="neutral-10" /> neutral-10 |
| **Size of body text**     |                    20                     |                         16                          |
| **Largest heading size**  |                    60                     |                         28                          |
| **Medium spacing length** |                    24                     |                         16                          |

(Values in pixels and for desktop.)

## Fidelity

Designs made with the design system look like finished pages from the start.
That polish can distract: customers may respond to visual details instead of the essence of a design, or think a website has already been built.

**Lo-fi Mode** (short for low fidelity) renders every component as a rough drawing to keep the conversation about structure and content.
All colours become shades of grey, text renders as handwritten squiggles, borders look drawn, and images show a crossed placeholder box.
Layout, sizing, and spacing remain unchanged, so pages keep their realistic structure.

Preview this mode through the theme switcher in the Storybook toolbar.
To use it in an application, import the Lo-fi tokens after the main stylesheet, together with its font – see the [Getting Started](/docs/docs-guidelines-getting-started--docs#lo-fi-mode) page for the import order, and the [tokens package readme](https://github.com/Amsterdam/design-system/blob/main/packages-proprietary/tokens/README.md) for scoping a mode with a class instead.
Lo-fi Mode combines freely with Compact Mode.
